# John Lemon's Haunted Jaunt

This is an older Unity project that I worked on during university while learning the basics of game development with Unity.

The project is based on the Unity Learn tutorial "John Lemon's Haunted Jaunt". As part of the university assignment, I had to extend the original project with additional features.

My main additions were:

- First-person camera
- Flashlight mechanic
- Jumpscare system

The project helped me practice working with player controls, cameras, lighting, triggers, audio, and basic gameplay scripting in Unity.

The project was later updated to a newer Unity LTS version!
